# Перші 10 секунд

**Інтерактивний тренажер домедичної допомоги з пошуком дефібриляторів за відкритими даними.**

Коли людина поруч раптово падає або сильно травмується, перші хвилини вирішують усе. Але більшість із нас губиться, бо не пам'ятає, що робити. «Перші 10 секунд» допомагає довести алгоритм дій до автоматизму: спершу коротка теорія, потім перевірка знань і, нарешті, сценарій на час, де кожен вибір має наслідки.

Проєкт створено командою з чотирьох людей на хакатоні **Python: Open Data** у Київській школі економіки (16 листопада 2026).

> ⚠️ Тренажер створено для навчання. Він не замінює курсів першої допомоги чи медичної консультації. У реальній ситуації спершу телефонуйте **103** або **112** і виконуйте вказівки диспетчера.

## Можливості

**Тренажер (головна сторінка)**

1. **Вибір теми** — одна з 6 невідкладних ситуацій.
2. **Конспект** — правильний алгоритм дій крок за кроком і джерело.
3. **Три питання** на перевірку з поясненням, якщо відповідь неправильна.
4. **Сценарій на час** — ситуація розвивається залежно від ваших виборів:
   - правильна дія веде до наступного кроку;
   - помилка має наслідки і супроводжується поясненням;
   - небезпечна дія завершує сценарій;
   - правильна відповідь, дана із запізненням, теж рахується як помилка.
5. **Підсумок** — кількість кроків і помилок, загальний час, найповільніший крок, графік часу на кожен крок і кругова діаграма результатів.

**Пошук дефібриляторів (сторінка «AED» у бічному меню)**

Користувач вводить координати, а програма знаходить найближчі автоматичні зовнішні дефібрилятори (АЗД) у Києві, показує їх у таблиці з відстанню та на карті.

## Запуск

Потрібен Python 3.10 або новіший.

```bash
pip install -r requirements.txt
streamlit run app.py
```

Програма відкриється в браузері. Сторінка пошуку дефібриляторів — у бічному меню зліва.

Для Windows, якщо команда не працює, спробуйте `py -m pip install -r requirements.txt` і `py -m streamlit run app.py`.

Перевірити дані на помилки:

```bash
python data_loader.py
```

Оновити дані про дефібрилятори з OpenStreetMap (потрібен інтернет): видаліть `data/aed_kyiv.csv` і виконайте

```bash
python open_data.py
```

## Формат даних

**`data/scenarios.csv`** — один рядок = один варіант відповіді на кроці сценарію:

| Стовпець | Значення |
| --- | --- |
| `topic_id` | код теми, наприклад `burns` |
| `node_id` | код кроку; перший крок теми — `<тема>_1` |
| `text` | опис ситуації на цьому кроці |
| `option` | варіант дії |
| `next_node` | куди веде вибір: інший крок, `END_OK` (успіх) або `END_FAIL` (провал) |
| `result` | `ok`, `mistake` або `fatal` |
| `explain` | пояснення до вибору |
| `time_limit` | скільки секунд дається на відповідь |

**`data/questions.csv`** — `topic_id`, `question`, `option_a`, `option_b`, `option_c`, `correct` (`a`, `b` або `c`), `explain`. Якщо в темі менше трьох питань, програма доповнює їх питаннями з кроків її сценарію.

**`data/topics.csv`** — `topic_id`, `title`, `summary`, `source`. Якщо конспект короткий, програма складає його з правильних дій сценарію.

**`data/choking.csv`** — сценарій у форматі «один крок = один рядок»: `step`, `question`, `option_a/b/c`, `correct_answer`, `time_limit`, `critical_on_error`, `explanation`. Програма автоматично перетворює його у формат сценаріїв.
