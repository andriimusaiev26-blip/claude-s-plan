# Інтерактивний тренажер домедичної допомоги

Навчальний командний проєкт для хакатону **Python: Open Data (KSE)**.

## Про проєкт

Ми створюємо застосунок на Python, який допомагає користувачам перевірити свої знання з домедичної допомоги в інтерактивному форматі. Користувач обирає ситуацію, відповідає на запитання та отримує пояснення до відповіді.

Застосунок призначений **для навчання, а не для медичної діагностики чи заміни екстрених служб**. У небезпечній ситуації слід телефонувати **103 або 112** і виконувати вказівки диспетчера.

## Навчальні сценарії

- Людина без свідомості, але дихає
- Опік
- Масивна кровотеча
- Людина вдавилася

## Можливості

У межах хакатону команда працює над такими функціями:

- вибір навчального сценарію;
- запитання з варіантами відповідей;
- перевірка відповідей і пояснення;
- таймер для навчального режиму;
- підрахунок результату;
- візуалізація статистики помилок;
- завантаження та перевірка даних із CSV.

## Технології

- **Python** — основна мова, обробка даних і логіка;
- **pandas** — робота з табличними даними;
- **Streamlit** — інтерфейс застосунку;
- **matplotlib** — графіки;
- **Git / GitHub** — командна робота.

## Структура проєкту


## Відкриті дані (Open Data)

Одна з обов'язкових умов хакатону — використати **реальні відкриті дані як основу роботи програми**.

**Можливе джерело для функції пошуку AED:** [OpenStreetMap](https://www.openstreetmap.org/), позначки `emergency=defibrillator` (через [Overpass API](https://overpass-api.de/)). Програма може обробляти координати з цього набору та визначати найближчі точки.

**Важливо:** створений командою CSV із навчальними запитаннями сам по собі не є підтвердженням виконання вимоги Open Data. Перед захистом потрібно переконатися, що програма дійсно завантажує й аналізує відкритий набір даних, зазначити конкретне джерело, умови використання та дату отримання даних.

Для змісту навчальних відповідей необхідно використовувати перевірені рекомендації з домедичної допомоги, зокрема [Resuscitation Council UK — Adult Basic Life Support (2025)](https://www.resus.org.uk/professional-library/2025-resuscitation-guidelines/adult-basic-life-support-guidelines). Ці рекомендації — джерело медичної інформації, а не заміна відкритого набору даних.

## Як запустити

Після того, як команда додасть файл `requirements.txt` з потрібними бібліотеками:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Для Windows, якщо команда `python` не працює, спробуйте `py` замість `python`.
